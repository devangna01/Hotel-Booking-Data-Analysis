# Hotel Booking Data Analysis



## Overview



This project explores hotel booking data to understand booking patterns, customer behavior, and factors related to booking cancellations. The analysis is performed in Python using a Jupyter Notebook.



## Project Files



- `Data Analysis (Hotel Booking).ipynb` — Jupyter Notebook containing the data analysis.

- `hotel\_bookings 2.csv` — Dataset used for the analysis.

- `Report.pdf` — Project report.



## Tools and Technologies



- Python

- Jupyter Notebook

- Pandas

- Data analysis and visualization



## Getting Started



1. Clone the repository:



```bash

git clone https://github.com/devangna01/Hotel-Booking-Data-Analysis.git

 ```



2. Navigate to the project directory:



```bash

cd Hotel-Booking-Data-Analysis

```



3. Install the required libraries:



```bash

pip install pandas jupyter matplotlib seaborn

```



4. Launch Jupyter Notebook:



```bash

jupyter notebook

```



5. Open `Data Analysis (Hotel Booking).ipynb` and run the notebook cells.

The project uses a CSV dataset containing hotel booking records.
